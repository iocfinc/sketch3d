SKETCH3D is a touch-first parametric 3D sketch modeler for iPad, Apple Pencil, and desktop web browsers. Draw 2D closed polygon profiles with 1mm/5mm/10mm grid snapping, drop calibrated metric screw holes (M2 2.2mm, M3 3.2mm, M4 4.2mm, M5 5.2mm with +0.2mm FDM clearance), extrude up to 256mm, bevel edges, apply axial twist, 3D hollow shelling, vase-mode surface texturing, scaled test-print proofs (40% Mini and 35mm Swatch), and export watertight binary STL files sized for the Bambu Lab A1 3D printer.
